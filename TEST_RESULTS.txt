家人安心记 0.2.0 图片功能验收记录
真实模型联调日期：2026-10-25；仓库发布回归日期：2026-10-26

完成的代码
- 本机网页单张图片上传、预览、移除及失败后重试；支持 JPEG/PNG/WebP，8 MiB 上限。
- 微信桥接支持指定群、指定成员的新图片，临时下载、校验和清理；引擎另接受 BMP。
- 图片接口独立配置 DeepSeek Flash，可同源复用已保存的文字 API 密钥；文字 Pro 独立运行。
- 仪表数字经两次独立识读一致后仅生成待确认记录。对象、实际时间和血糖餐次须人工核对；不能自动入账或调药。
- 食物照片提供受限名称和一般饮食提示，不推断克数、糖盐含量或治疗食谱。

验证结果
- 128 项本地自动测试通过，含25项微信桥接模拟测试，以及默认档案留空、已有档案保留的发布回归测试。
- JavaScript 语法检查通过。此次新增图片界面的浏览器交互验收未完成：电脑工具无法可靠确认浏览器地址并结束操作。
- 使用已授权的真实 API 在隔离环境中联调：DeepSeek V4 Pro 文字问答返回成功。
- 最终版 Flash：公开血压仪图片读出120/80 mmHg；公开血糖仪图片读出5.3 mmol/L，两次识读一致。
- 上述两条测试均验证：缺实际时间不能确认；显式确认后才写入隔离测试数据库。
- 缺单位的合成仪表图不生成测量记录。
- 测试记录、测试图片、运行环境和密钥均不放入ZIP。正式数据目录未写入测试读数。

准确率限制与修正依据
这不是识别准确率统计。在增加独立复核之前，同一张横置5.3 mmol/L照片曾被读成5.7（被不确定性规则拦下），也曾读成5.9（仅成为待确认草稿，未保存）。因此增加独立复核；最终一次联调读出5.3不表示以后一定正确。两次模型也可能共同看错，使用者仍须对照仪器核对。

部署与未验收范围
- 仓库不包含密钥、个人档案、健康数据库或运行环境。新安装的档案字段留空或标注未知；已有本机档案继续从不受版本控制的data目录读取。
- 更新运行中的服务需先双击stop.cmd，再双击start.cmd。图片识别需要自行配置支持图片的模型及密钥。
- 真实普通微信群尚未完成验收；没有通过该桥接发送实际微信消息。仍需匹配客户端和授权后在测试群验收。
