怎样选，才适合这个助手

先用 DeepSeek Flash 或通义千问 Flash 做小规模饮食问答试用，再用相同的真实问题比较是否遵循医嘱边界、回答清楚。这个建议基于国内接入便利性和已核对价格，尚未进行医疗问答质量评测。更贵的模型不自动意味着更安全。

提醒、读数保存、确认和固定异常规则都在本机执行，不必每次调用模型。模型只负责解释一般饮食问题。首版支持兼容 /chat/completions 的接口；表中列出价格不代表对应原生接口已全部接入验证，Claude 原生 Messages 接口尚未单独适配。

选择后，到工作台的“家庭设置 → 模型接口”填写官方 API 地址、模型名和自己的密钥，再启用。请先核对所在地域、账号可用性与数据处理条款，不将密钥发到微信群。

读价格表时需要区分的条件

  • DeepSeek 峰时为北京时间工作日（法定节假日除外）09–12、14–18，其余闲时。实际费用按请求发生时间加权；表中范围不是套餐承诺。
  • 通义千问本行使用北京地域短输入档。32K–256K 的输入/输出为 ¥0.60/¥2.40，256K–1M 为 ¥1.20/¥4.80。显式缓存创建按普通输入的125%收费，读取10%，TTL为5分钟；隐式命中20%，两类互斥。
  • 豆包本行是常规在线推理，非低优或精调价格。32K–128K 为 ¥0.40/¥4，128K–256K 为 ¥0.80/¥8；缓存存储另计 ¥0.017/百万 tokens/小时。模型ID可在官方计费表核对。
  • GLM 是国际站美元价；国内站实时人民币价格本次未完成核验。缓存存储当前为限时免费，不保证持续。
  • GPT-6 Luna 长输入档的输入/输出/缓存为 US$0.20/0.75/0.02。短输入档的30分钟/12小时缓存写入为 US$0.125/0.25；地区驻留处理可能另加10%。
  • Claude Haiku 输入超过100K后，输入/输出/缓存为 US$0.50/2.50/0.05。Haiku的5分钟/1小时缓存写入为 US$0.125/0.20；Sonnet为 US$2.50/4。US-only推理另加10%。
  • 上下文分档按单次请求判断；用量包括系统提示、必要的聊天历史和可能计费的推理输出。免费额度、活动价格和批处理折扣不用于本表统一估算。
